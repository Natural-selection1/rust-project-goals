# 2026 年语言特性总结

### 1. 编译期能力 (Compile-time Capabilities)

- `const-generics`
  完成 const 泛型的剩余部分，重点支持抽象数据类型（ADT，如结构体和枚举）作为泛型参数，以及在关联常量中使用复杂的常量表达式。

- `const-traits`
  允许在 `const fn` 中调用 trait 方法，支持泛型 trait 的编译期实现，并推进标准库中关键 trait 的 `const` 化，大幅增强编译期计算能力。

- `macro-improvements`
  持续改进声明式宏（`macro_rules!`），目标是使其表达能力比肩过程宏，并稳定声明式属性宏和派生宏，降低宏开发的门槛。

- `reflection-and-comptime`
  设计并实验性地实现一种基于 `const fn` 的编译期反射方案，旨在无需过程宏即可实现类型信息的编译期提取（如自动生成序列化逻辑）。

### 2. 变量与内存 (Variables and Memory)

- `in-place-init`
  探索并确定一种在最终内存位置直接构造对象的“原地初始化”方案，以消除不必要的移动（move）开销，特别是在处理大型结构体或不安全代码时。

- `manually_drop`
  引入 `#[manually_drop]` 属性或改进 `Destruct` trait，允许开发者更精确地控制结构体字段的析构行为，优化资源管理。

- `move-trait`
  引入 `Move`、`Destruct`、`Forget` 等显式 trait，允许类型选择性地禁止移动或强制析构。这有助于简化 `Pin` 的语义，并更好地支持不可移动类型。

- `super-let`
  重新设计并稳定“超级 let”（Flexible Temporary Lifetime Extension），通过一种安全的方式扩展临时变量的生命周期，解决宏返回值生命周期过短的痛点。

- `scalable-vectors`
  稳定 `Sized` trait 的分级体系（Sized Hierarchy），以支持 AArch64 SVE 和 SME 等在运行时才能确定向量宽度的硬件架构。

- `stabilizing-f16`
  正式稳定 `f16`（半精度浮点数）类型，并推进 `f128` 的支持，以满足 AI 推理、图形渲染和科学计算中对极致性能和精度的需求。

### 3. 表达力 (Expressiveness)

- `arbitrary-self-types`
  解耦 `Deref` 和 `Receiver` trait，允许自定义智能指针（如 `CMut<T>`）直接作为方法接收者，并支持 `dyn Trait` 的透明强制转换。

- `reborrow-traits`
  引入 `Reborrow` 和 `CoerceShared` trait，使得像 `Pin<&mut T>` 这样的自定义包装类型也能像原生引用一样实现“自动重借用（autoreborrow）”。

- `rtn` (Return Type Notation)
  稳定 `T::method(..): Send` 这种返回类型表示法，彻底解决异步 trait 中 `Send` 边界（Send bound）的表达难题。

- `specialization`
  稳定一个受限的、始终适用的（always applicable）特化子集，允许基于具体类型提供更高效的 trait 实现，同时规避传统特化带来的声音性问题。

- `never-type`
  稳定 `!` 类型（never type），解决遗留的类型推导 fallback 问题，使错误处理和流控制的代码更加严谨。

- `try-trait`
  稳定 `Try` trait，允许开发者自定义 `?` 运算符的行为（如在错误传播时自动捕获回溯或上下文），增强错误处理系统的扩展性。

- `supertrait-auto-impl`
  实现父类（supertrait）的自动实现机制，简化 trait 层次结构的重构过程，允许在不破坏下游代码的前提下为现有 trait 添加父类约束。

- `tail-call-loop-match`
  引入显式尾调用（explicit tail calls）支持，并优化 `loop` 与 `match` 组合的性能，为函数式编程范式和状态机实现提供性能保障。

- `unsafe-fields`
  稳定不安全字段（unsafe fields）特性，允许将特定字段标记为携带安全不变量，强制对其修改必须在 `unsafe` 块中进行。

### 4. 易用性 (Usability)

- `afidt-box`
  引入 `.box` 符号支持，通过简单的语法开启异步 trait 的动态派发，让调用方自主决定是否承担堆分配开销，兼顾灵活性与性能。

- `ergonomic-rc`
  通过 `Share` trait 等手段提升引用计数的人体工学，并引入 `move($expr)` 语法，允许在不使用“克隆后再捕获”模板代码的情况下精确控制闭包。

- `field-projections`
  设计并实现字段投影（field projections）方案，使得通过智能指针或固定引用（`Pin`）直接访问结构体内部字段变得像 `&x.field` 一样自然。

- `pin-ergonomics`
  继续深化 Pin 人体工学实验，包括探索 `&pin mut` 语法和 `Drop::pin_drop` 机制，降低编写异步底层代码的复杂度。

# 2026 年语言特性总结

### 1. 编译期能力 (Compile-time Capabilities)

- [const-generics](提案索引/语言特性/编译期能力/const-generics.md)
  将当前最小化的 const 泛型扩展为更完整、协调的语言能力，包括更丰富的参数类型及常量表达式支持。

- [const-traits](提案索引/语言特性/编译期能力/const-traits.md)
  完善 const traits RFC 并解决编译器中的剩余问题，推动常量上下文中的 trait 调用及相关标准库能力走向稳定化。

- [macro-improvements](提案索引/语言特性/编译期能力/macro-improvements.md)
  继续增强声明式宏，优先推进声明式属性宏和 derive 宏稳定化，并原型化新扩展及探索与编译期求值的协作。

- [reflection-and-comptime](提案索引/语言特性/编译期能力/reflection-and-comptime.md)
  完善基于仅能在编译期调用的 `const fn` 的反射方案，通过现有反射库验证并准备 RFC；本阶段聚焦产生常量求值结果。

### 2. 变量与内存 (Variables and Memory)

- [allocators-1.0](提案索引/语言特性/变量与内存/allocators-1.0.md)
  推动标准库对自定义分配器的原生支持，重建 allocator 工作组，并优先稳定 `Allocator` 等核心 API，逐步扩展安全接口。

- [contracts-ownership-assertions](提案索引/语言特性/变量与内存/contracts-ownership-assertions.md)
  实现 `owned`、`alloc_block` 所有权断言及其封装，并接入 Miri 动态验证，配套文档和教程以支持 unsafe 内存操作的规约与验证。

- [in-place-init](提案索引/语言特性/变量与内存/in-place-init.md)
  评估不同的原地初始化方案，与 lang 团队形成推荐方向，减少大型或不可移动对象构造时不必要的移动。

- [manually-drop-attr](提案索引/语言特性/变量与内存/manually-drop-attr.md)
  提供更直接的结构体字段析构控制，支持调整析构顺序和禁用递归析构，改善跨语言绑定及手动管理析构的体验。

- [move-trait](提案索引/语言特性/变量与内存/move-trait.md)
  探索 `Move`、`Destruct`、`Forget` 等能力 trait，让类型显式表达可移动、可析构和可遗忘的约束，并通过编译器 MVP 与 Linux 内核用例验证设计。

- [redesigning-super-let](提案索引/语言特性/变量与内存/redesigning-super-let.md)
  重新讨论 `super let` 的设计并编写 RFC，推进更灵活的临时值生命周期延长机制及其稳定化准备。

- [scalable-vectors](提案索引/语言特性/变量与内存/scalable-vectors.md)
  推进不依赖 constness 的 `Sized` 层级稳定化以支持 extern types，同时继续 SVE 类型、intrinsic 和相关设计的 nightly 实验，并探索 SME 支持。

- [stabilizing-f16](提案索引/语言特性/变量与内存/stabilizing-f16.md)
  解决标准库和编译器中的剩余工作，推进 `f16` 在 LLVM 与 Cranelift 后端上的支持和稳定化；本提案当前聚焦 `f16`。

### 3. 表达力 (Expressiveness)

- [arbitrary-self-types](提案索引/语言特性/表达力/arbitrary-self-types.md)
  推进自定义智能指针作为方法接收者、向 trait 对象转换等能力，缩小用户定义指针与标准库指针的差距，并探索 `Deref`/`Receiver` 的解耦。

- [library-trait-evolution-experiment](提案索引/语言特性/表达力/library-trait-evolution-experiment.md)
  汇集标准库和生态中的 trait 演进需求，联合探索 refined trait implementations、supertrait auto-impl 等功能，降低 trait 定义和实现的僵化程度。

- [reborrow-traits](提案索引/语言特性/表达力/reborrow-traits.md)
  将 `Reborrow` 和 `CoerceShared` 带入 nightly 并收集反馈，继续处理多生命周期、字段重排等复杂情况，以及必要的安全验证和 RFC 修订。

- [rtn](提案索引/语言特性/表达力/rtn.md)
  共同准备 TAIT 与返回类型表示法（RTN）的稳定化，让用户能够命名 opaque 类型并表达返回值约束，同时探索 RTN 对异步闭包的支持。

- [specialization](提案索引/语言特性/表达力/specialization.md)
  收集特化用例与设计约束，建立健全的最小方案并在编译器中实现，为后续稳定化打基础。

- [stabilize-never-type](提案索引/语言特性/表达力/stabilize-never-type.md)
  解决 `!` 类型相关的 fallback、强制转换和诊断等剩余问题，推进 never type 稳定化。

- [stabilize-try](提案索引/语言特性/表达力/stabilize-try.md)
  解决 `Try` trait 的剩余设计问题，或以保留后续演进空间的受限方案稳定核心能力，使用户能自定义 `?` 运算符行为。

- [supertrait-auto-impl](提案索引/语言特性/表达力/supertrait-auto-impl.md)
  实现 supertrait `auto impl` RFC 的核心能力，处理实现重叠及可选功能，并通过标准库 trait 重构验证方案。

- [tail-call-loop-match](提案索引/语言特性/表达力/tail-call-loop-match.md)
  继续实现显式尾调用与 `loop_match`，解决跨平台尾调用限制并改善分支密集代码的生成质量。

- [unsafe-fields](提案索引/语言特性/表达力/unsafe-fields.md)
  补齐 unsafe fields 的 Clippy、rustdoc、rustfmt 和文档支持，完成稳定化准备，使携带安全不变量的字段获得显式标记及操作约束。

### 4. 易用性 (Usability)

- [afidt-box](提案索引/语言特性/易用性/afidt-box.md)
  设计并实现通过 `dyn` trait 对象调用原生 `async fn` 方法的能力，处理返回 Future 的动态派发与存储问题。

- [ergonomic-rc](提案索引/语言特性/易用性/ergonomic-rc.md)
  原型化表示共享底层值语义的 `Share` trait，以及控制闭包捕获时机和内容的 `move($expr)` 表达式，为引用计数易用性改进打基础。

- [field-projections](提案索引/语言特性/易用性/field-projections.md)
  探索 virtual places 字段投影方案，整理设计及其与其他特性的交互，开展编译器实验并据此准备 RFC。

- [pin-ergonomics](提案索引/语言特性/易用性/pin-ergonomics.md)
  继续实验和完善 Pin 易用性方案的设计与语义，降低固定引用及底层异步代码的使用负担。

- [view-types-experiment](提案索引/语言特性/易用性/view-types-experiment.md)
  在 rustc 中实验 view types 及不同语法，让类型表达可访问的字段集合，改善局部借用；本期以验证设计为主，不面向生产使用。
